# Screenshots

Everything for Activity Log's App Store / Google Play screenshots. This is
configuration for the shared workspace [`screenshots`](../../screenshots)
tools; neither tool lives here.

| Folder | Used by | What's in it |
| --- | --- | --- |
| [`assets/`](assets) | [`screenshots/studio`](../../screenshots/studio) | The slide deck (`app-store-screenshots.json`) and the raw device screenshots it uses. |

Activity Log's raw screenshots aren't captured automatically yet. To set that up, add
a `capture/` folder here; see [`screenshots/capture`](../../screenshots/capture)
and Anglers' Log's `screenshots/capture/` for an example.
